# backups/

영구 보관용 데이터 백업. 코드 리포지토리와 함께 버전 관리.

## 파일 명명 규칙
`YYYY-MM-DD-<사유>.json`

## 보관된 백업

| 파일 | 시점 | 사유 | 출처 |
|---|---|---|---|
| `2026-06-03-pre-rewrite.json` | 2026-06-03 | 신규 앱 재설계 직전 마지막 v2 데이터 스냅샷 | 앱 "백업 다운로드" 버튼 |

## 복원 절차

1. 신규 앱(v3) 첫 부팅 시 v2 데이터가 없거나 손상되면:
2. 앱 헤더의 "엑셀 가져오기" 옆 "백업 복원" 버튼 → 본 JSON 선택
3. v2→v3 자동 변환 후 적용
4. 변환 결과는 화면에서 검증 (제품 수·원료 수·발주 코드 일치)

직접 변환이 필요한 경우:
- `v2/modules/migrations.js`의 `normalizeV2State` + 신규 `migrateV2toV3` 사용
- 둘 다 순수 함수이므로 Node.js나 브라우저 콘솔에서 검증 가능
