# 레시피 엑셀 일괄 등록 핸드오프

## 현재 상태

`index.html`에 엑셀 일괄 등록 기능을 추가했다.

상단 헤더에 `엑셀 가져오기` 버튼이 있으며, `.xlsx`/`.xls` 파일을 선택하면 브라우저에서 파일을 읽어 현재 앱 데이터로 변환한다.

## 변경 파일

- `index.html`
  - `엑셀 가져오기` 버튼 및 hidden file input 추가
  - SheetJS CDN 스크립트 추가
  - 엑셀 파싱/변환/중복 처리/저장 함수 추가
- `레시피_엑셀_일괄등록_스펙.md`
  - 지원 엑셀 구조와 처리 규칙 정리
- `레시피_엑셀_일괄등록_핸드오프_2026-05-13.md`
  - 이 문서

## 주요 함수

- `openExcelImport()`
  - hidden file input을 클릭한다.
- `handleExcelImport(event)`
  - 사용자가 선택한 엑셀 파일을 읽고 파싱을 실행한다.
- `parseRecipeWorkbook(workbook, fileName)`
  - 첫 번째 시트를 4열 단위 제품 블록으로 읽어 앱 제품 배열로 변환한다.
- `inferSpeciesFromFile(fileName, sheetName)`
  - 파일명/시트명에서 `고양이` 또는 `강아지`를 추론한다.
- `withSpeciesPrefix(name, species)`
  - 제품명에 `(고양이)` 또는 `(강아지)` 접두어를 붙인다.
- `importProducts(products)`
  - 기존 상태와 비교하여 새 제품 추가/기존 제품 덮어쓰기를 수행하고 저장/렌더링한다.

## 구현 규칙

- 제품 블록은 4열 간격으로 읽는다.
- `rowIndex < 12`는 원료, `rowIndex >= 12`는 영양제/첨가제로 본다.
- 제품별 첫 번째 원료는 생산단위 원료로 자동 지정한다.
- 같은 제품명은 기존 제품 `id`를 유지한 채 덮어쓴다.
- 가져오기 후 `saveRecipeData()`, `renderProducts()`, `syncPriceTab()`, `renderOrderTab()`, `renderPreviewTab()`을 호출한다.

## 주의 사항

- 현재 SheetJS는 CDN으로 불러온다. 오프라인 환경이면 가져오기가 실패한다.
- `restore.html`과 `recipesss-localstorage-recovered.json`은 이전 복구 작업용 임시 파일이다. 기능과 직접 관련은 없지만 현재 저장소에 남아 있다.
- `index.local-backup-before-redownload.html`은 추적되지 않은 백업 파일로 남아 있다.
